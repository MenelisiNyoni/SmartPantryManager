# Smart Pantry Manager

Smart Pantry Manager is an Android application designed to help users track their pantry inventory and automatically suggest recipes based on available ingredients.

## Features
- **Pantry Management**: Add, update, and delete ingredients with quantities and units.
- **Recipe Suggestions**: Intelligent recipe matching utilizing string normalization (trimming, case sensitivity, and basic singular/plural handling).
- **Settings & Preferences**: Customizable user preferences stored using `SharedPreferences`.
- **Database**: Local SQLite storage via `SQLiteOpenHelper`.

## Tech Stack
- **Language**: Java / Kotlin
- **Database**: SQLite
- **UI Framework**: Android XML / Material Components
- **Architecture**: Android SDK standard architecture
